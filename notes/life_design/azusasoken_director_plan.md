### 提案1：「標準化プレミアム」戦略

**発想の核心**  
BIM属性管理プラットフォームで「業界標準」を握った瞬間、AIR-Plateは単なる製品から「標準の実装リファレンス」に昇格する。これは競合が価格で戦えない世界を作る。

**具体的なメカニズム**
```
国交省の属性情報リスト
        │
        ▼（梓総研が管理・更新を担う）
  BIM標準属性データベース
        │
        ▼（「この標準に準拠した唯一のツール」として）
     AIR-Plate
        │
        ▼（「標準化対応できていますか？」という問いかけで）
    AIコンサル受注
```

**なぜ強いか**
- 競合他社はAIR-Plateに対抗しようとしても、「標準に準拠しているか」という比較軸で不利になる
- 標準は一度決まると変えにくく、先行者優位が長期間持続する
- 国交省・大学との連携という「公的正当性」は民間企業が簡単に複製できない

**2026年度の具体アクション**
- [ ] AIR-Plateが「BIM標準準拠ツール」として位置づけられる準備を開始（機能マッピング）
- [ ] 芝浦工大WGで「AIR-Plateと標準属性の連携」を研究テーマとして提案
- [ ] 「標準準拠ツールとしてのAIR-Plate」を訴求する営業資料を作成

### 提案2：「コンソーシアム＝顧客獲得エンジン」設計

**発想の核心**  
BIMコンソーシアムに参加する企業（メーカー・ゼネコン・設計事務所）は、標準化への対応を迫られる。その「対応支援」がAIコンサルの自然な受注につながる。コンソーシアムは顧客獲得コストゼロの営業組織として機能する。

**顧客ライフサイクルの設計**
```
Step 1: BIMコンソーシアムへの参加招待
        （「業界標準を一緒に作りましょう」）
        ↓
Step 2: 標準化への対応が必要になる
        （「自社の設計・製品情報をBIM標準に合わせるには？」）
        ↓
Step 3: AIコンサルを受注
        （「梓総研に任せれば標準準拠できる」）
        ↓
Step 4: AIR-Plateを導入
        （「このツールで標準化運用を継続できる」）
        ↓
Step 5: 長期的なプラットフォーム利用者に
        （解約しにくいロックイン）
```

**ポイント**: 一度このサイクルに入った企業は「出る理由がない」エコシステムになる。

**2026年度の具体アクション**
- [ ] コンソーシアム参加企業の「入会後の標準化対応ニーズ」を想定し、AIコンサルのサービスメニューに明示する
- [ ] コンソーシアムへの招待リストをAIコンサルのターゲット企業リストと重ねて作成
- [ ] コンソーシアム参加企業向けの「標準化準拠チェックリスト」をAIコンサルのフロントエンド商品として設計

### 提案3：データフライホイール（建築AIデータ資産の独占）

**発想の核心**  
3事業を通じて蓄積されるデータを組み合わせると、他社が持てない「建築AIデータセット」が生まれる。このデータは将来的に最大の参入障壁になる。

**3事業が生み出すデータ**

| 事業 | 蓄積されるデータ | 価値 |
|---|---|---|
| AIR-Plate | 建築設計・施工の業務データ、ユーザー行動データ | 建築業務のリアルな実態 |
| AIコンサル | AI導入事例、失敗事例、業種別の課題データ | 建築AI活用の知見 |
| BIMプラットフォーム | 業界標準の属性定義、メーカー・仕様書データ | 建築の構造化知識 |

**これらが合わさると**
```
建築業務データ（How） × AI活用知見（Why） × 標準属性定義（What）
= 他社が絶対に持てない「建築AI学習データセット」
```

**将来の展開可能性**
- 建築AI SaaSのトレーニングデータとして提供（データビジネス）
- 業界レポート・インサイト販売
- 起業後の会社の中核資産として活用

**2026年度の具体アクション**
- [ ] 3事業のデータをどのように統合・管理するかの設計図を作成
- [ ] AIR-Plateのデータ収集・分析基盤の強化を検討（収集項目の見直し）
- [ ] AIコンサルの事例をナレッジベースとして蓄積する仕組みを構築

### 提案4：「建築DX道場」人材エコシステム

**発想の核心**  
3事業を「人材の成長パス」として設計する。梓総研が建築DX人材の「育成・輩出センター」になることで、優秀な人材が自然と集まる磁場を作る。これが取締役就任の「組織的な正当性」にもなる。

**人材の成長ロードマップ**
```
AXタスクフォース参加
        │（建築×AIの基礎体験）
        ▼
AIR-Plateの運用・営業で実践
        │（顧客対応・事業運営の経験）
        ▼
AIコンサルのジュニアコンサルタント
        │（外部クライアントとの実践・単価向上）
        ▼
BIM標準化WGやコンソーシアムで業界影響力を持つ
        │（業界の顔になる）
        ▼
梓総研から独立 or 幹部として残留
```

**石川さんのポジション**
この道場の「館長」として、建築DX人材を育て、業界全体に影響力を持つ存在になる。これが「取締役候補」としての最大の評価軸になる。

**2026年度の具体アクション**
- [ ] タスクフォースで発見した優秀な人材に「梓総研でのキャリアパス」を明示的に提示する
- [ ] AIコンサル事業のジュニアポジションをAXタスクフォース内で公募（インセンティブ付き）
- [ ] 「建築DX人材育成」を梓総研の対外的なブランドメッセージとして打ち出す

### 提案5：「公的権威×民間実装」の差別化

**発想の核心**  
芝浦工大WG・国交省との連携は、他の民間コンサル会社が絶対に持てない「公的正当性」を付与する。これをAIR-PlatやAIコンサルの差別化要因として積極的に使い切る。

**競合との差別化マップ**

| 比較軸 | 一般的なAIコンサル | 梓総研（石川さん） |
|---|---|---|
| 技術力 | あり | あり |
| 建築専門知識 | 限定的 | 設計事務所の実践知 |
| 業界標準への影響力 | なし | **国交省・芝浦工大連携** |
| 政府・大学との信頼性 | なし | **あり（実績として提示できる）** |
| 実際の導入実績 | 他業種が多い | **建築業界のリアルな実績** |

**外部発信への活用**
- WGでの研究成果を論文・レポートとして発表 → AIコンサルの「お墨付き」に
- 国交省の政策動向の解説コンテンツを発信 → 業界内のKOL（Key Opinion Leader）ポジション確立
- 芝浦工大との共同セミナー開催 → AIコンサルのリード獲得

**2026年度の具体アクション**
- [ ] 芝浦工大WGの研究成果を業界セミナーで発表する機会を作る（2026年度中に1回）
- [ ] 国交省BIM政策の動向をわかりやすく解説するレポートを四半期ごとに作成・配布
- [ ] 「設計事務所が実践したAI活用事例」を外向けにコンテンツ化（AIR-Plate・AIコンサルの営業資料に転用）

### 提案6：2027年10月起業への「エコシステムごと持ち出す」設計

**発想の核心**

```
┌─────────────────────┐     ┌─────────────────────┐

└─────────────────────┘     └─────────────────────┘
         │                              │
```
