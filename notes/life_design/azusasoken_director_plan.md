# 梓総研取締役就任・独立採算体制構築 アクション計画

> 最終更新: 2026-06-15  
> 対象期間: 2026年6月 〜 2027年10月（起業）

---

## 背景・目標

| 項目 | 内容 |
|---|---|
| 現職 | 梓設計 AXチーム 部長 |
| 役割（実態） | 梓総研の実質的な事業部長 |
| 目標① | **2027年4月** 梓総研取締役就任（梓設計在籍のまま） |
| 目標② | **2027年10月**（55歳）起業 |
| 目標③ | **2028年10月** 年収4500万円（＋3000万円）達成 |

### 核心姿勢

- 「なりたい」ではなく「すでになっている」として動く
- 弱気な戦略は切り捨てる。部下への影響は最大
- AIR-Plateの売上と経営戦略管理を自分が握る
- 周囲が圧倒的に認める実績で人事を動かす

- [ ] 営業力のあるメンバートップ2名を特定
- [ ] 取締役への月次報告フォーマットを作成・共有提案

**7/8〜7/14（新規顧客ルート開拓）**

- [ ] 弱気な戦略・慣習をリストアップし、廃止候補を取締役に提案

## Phase 2：拡大証明（2026年10〜12月）

### 月次テーマ

| 月 | テーマ |
|---|---|
| 10月 | AIR-Plate売上の「急拡大」を実証 |
| 11月 | 独立採算P/Lの実運用開始 |
| 12月 | 取締役候補として周囲に認知される |

### 毎週固定アクション（Phase 2）

| タイミング | 内容 |
|---|---|
| 月曜AM | AIR-Plate週次パイプライン更新・メンバーへの指示出し |
| 水曜 | 新規・既存顧客へのアクション最低1件 |
| 金曜 | 週次実績記録（売上・アポ件数・課題）→ 蓄積 |

### 10月 重点アクション
- [ ] 年内の新規契約3件以上を目標に商談を集中的に進める
- [ ] AIR-Plateの価格戦略を見直し（値上げ or 上位プラン設計）
- [ ] 梓総研の決算・会計情報を自分が把握できる体制を確立

### 11月 重点アクション
- [ ] 独立採算体制の試行開始（梓総研内の自チーム分でPL作成）
- [ ] 梓設計・梓総研の「二重在籍」モデルの法務・労務上の確認を専門家に相談
- [ ] 梓設計の上長・人事に「梓総研取締役就任」の意向を正式に伝える面談を設定

### 12月 重点アクション
- [ ] 2026年度の総括レポートを作成（売上実績・組織変革・戦略遂行状況）
- [ ] 梓総研取締役からの信任を確認（直接会話）
- [ ] 2027年度の梓総研事業計画を自分主導で作成し、役員会に提出
